# Week 5 Assignment
## Purpose 
The purpose of this assignment is to reinforce Sass organization, reusable styles, responsive design, and modern layout techniques. Students will build a responsive landing page based on the provided prototype, organizing their styles with Sass partials, variables, nesting, and mixins.

##Instructions
Using the provided prototype as a visual guide, build a responsive landing page using HTML, CSS, and Sass.


 

## Sass Requirements

Your project must use Sass and include:

At least one variable file
At least one mixins file
At least one additional partial file
Nested selectors where appropriate
At least one custom mixin
## Layout Requirements

Use both:

CSS Grid
Flexbox
 ## Responsive Requirements

Your website must include responsive layouts for:

Desktop
Tablet
Mobile
The mobile version must:

Display a navigation icon instead of the full navigation menu
Stack content into a single-column layout
Maintain readable typography and spacing
